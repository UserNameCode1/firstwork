# Ejercicio 6: La Forja Mágica de Steve ⚒️

Este proyecto consiste en un sistema de modelado de herramientas de Minecraft utilizando **Programación Orientada a Objetos (POO)** en Python. El objetivo principal es aplicar conceptos avanzados de abstracción y encapsulamiento.

## 🎯 Objetivo
Modelar una fábrica de herramientas donde cada objeto tiene un material, un nivel de durabilidad y una acción específica (minar, atacar o excavar), gestionando el desgaste de forma automática.

## 🧠 Conceptos Aplicados
* **Clases Abstractas (ABC):** Uso de la base `Herramienta` para definir una interfaz común.
* **Polimorfismo:** Cada herramienta implementa su propio método `usar()` de manera distinta.
* **Encapsulamiento:** Atributos protegidos (como `_material`) para controlar el estado interno.
* **Decoradores (@property):** Implementación de getters y propiedades abstractas.
