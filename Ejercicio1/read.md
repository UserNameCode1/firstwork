# Ejercicio: Gestión de Estudiante

## Introducción
En este ejercicio se desarrolla un sistema básico para gestionar la información académica de un estudiante. Se enfoca en la administración de calificaciones, asegurando que se calculen promedios de forma correcta y se determine el estado académico del alumno.

## Especificaciones del Código
- **Clase:** `Estudiante`
- **Atributos:** `nombre`, `edad` y `notas`.
- **Funcionalidades:**
    - **Registro de Notas:** Permite añadir calificaciones a una lista interna.
    - **Cálculo de Promedio:** Genera la media aritmética de todas las notas registradas.
    - **Estado Académico:** Determina si el estudiante aprueba o reprueba según su promedio final.
    - **Consulta:** Permite visualizar un resumen con los datos generales del estudiante.

## Conceptos Aplicados
- Programación Orientada a Objetos (POO).
- Manejo de listas y colecciones.
- Lógica de control con condicionales (`if/else`).
- Métodos para el procesamiento de datos.
