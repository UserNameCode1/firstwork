# Ejercicio 4a: Sistema de Gestión de Restaurante 🍽️

## Introducción
Este ejercicio simula la administración de un restaurante, manejando elementos como el menú y la disponibilidad de mesas. Es ideal para practicar el manejo de listas y colecciones dentro de una clase.

## Especificaciones del Código
- **Clase:** `Restaurante`
- **Atributos:** `nombre_restaurante`, `tipo_cocina` y `menu` (lista).
- **Funcionalidades:**
  - `describir_restaurante()`: Muestra información general del lugar.
  - `abrir_restaurante()`: Cambia el estado del local a abierto.
  - `agregar_al_menu()`: Permite expandir la lista de platos disponibles.

## Conceptos Clave
- Modelado de sistemas del mundo real.
- Manipulación de listas en Python.
