# Ejercicio 4: Simulador de Combate (Guerrero) 

## Introducción
Este proyecto modela la estructura de un personaje de juego de rol (RPG). Se centra en la gestión de atributos de combate como salud y fuerza, permitiendo simular ataques y recibir daño.

## Especificaciones del Código
- **Clase:** `Guerrero`
- **Atributos:** `nombre`, `nivel`, `salud` y `fuerza`.
- **Métodos:**
  - `atacar()`: Calcula el daño basado en la fuerza.
  - `recibir_daño()`: Reduce la salud del guerrero tras un ataque enemigo.
  - `esta_vivo()`: Verifica si la salud es mayor a cero.

## Objetivo
Practicar la interacción entre objetos y la actualización dinámica de atributos durante la ejecución.
